# 성인인증 플랫폼 정책

최종 업데이트: 2026-07-07

## 공통 정책

- 성인 카테고리는 성인인증 완료 계정에 한해서만 허용한다.
- 성인 카테고리는 신고, 차단, 금칙어 필터링, 운영자 검토를 전제로 운영한다.
- 불법 촬영물, 아동·청소년 대상 성착취물, 개인정보 노출 콘텐츠는 즉시 제한 대상이다.
- 성인방은 프로모션/탑스페이스/공개 추천 노출에서 제외한다.

## iOS

- iOS 앱에는 성인 탭을 노출하지 않는다.
- 성인방 생성/편집 옵션은 비활성화한다.
- 앱 안에서 외부 인증 링크나 우회 안내를 보여주지 않는다.
- App Store 심사 메타데이터에서도 성인 콘텐츠 접근 경로가 보이지 않도록 한다.

## Android

- Android도 인증 전에는 성인 탭을 노출하지 않는다.
- 인증 완료 후에만 성인 탭과 성인방 생성이 가능하다.
- Google Play Console 처리는 사용자가 수동으로 진행했다.
- Android 구현은 iOS와 병렬로 가되, iOS 심사용 코드와 노출 정책을 깨지 않도록 분리한다.

## 웹

- 성인인증은 외부 웹에서 로그인 후 진행한다.
- 웹에서는 회원가입을 제공하지 않는다.
- 로그인 전 성인 카테고리 상태 섹션은 숨긴다.
- 인증 계약 완료 후 실제 본인확인/성인확인 API를 연결한다.
