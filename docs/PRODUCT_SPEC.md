# 뮤트 제품 명세

최종 업데이트: 2026-07-07

## 제품 개요

뮤트는 전화번호 기반 익명 커뮤니티 채팅 앱이다. 계정은 전화번호로 인증하되, 방 안에서는 방별 프로필 이름과 사진으로 활동한다.

## 핵심 원칙

- 계정 정보는 최소 노출한다.
- 방마다 다른 프로필을 사용할 수 있다.
- 채팅, 스토리, 댓글, 신고, 차단은 실시간에 가깝게 반영한다.
- iOS 심사용 빌드에서는 성인 카테고리와 성인 인증 동선을 노출하지 않는다.
- Android 성인 카테고리는 별도 정책 문서 기준으로 나중에 병렬 적용한다.

## 주요 화면

- 로그인/회원가입
- 내 채팅
- 홈
- 공개 스토리
- 내 정보
- 방 소개/스토리
- 채팅방
- 멤버 관리
- 아이템샵
- 포인트 내역
- 설정
- 운영자 신고 확인 웹

## 채팅

- 텍스트, 사진, GIF, 답장, 하트, 포인트 전송, 비밀쪽지, 공지선 지원
- 내가 보낸 메시지는 5분 이내 소프트 삭제 가능
- 탈퇴/퇴장한 멤버의 과거 채팅은 당시 프로필로 보존
- 방 입장 전 메시지는 신규 멤버에게 보이지 않는다.
- 오래된 메시지는 위로 스크롤할 때 페이지 단위로 로딩한다.
- 검색은 검색 버튼을 누른 뒤 전수 검색하고, 준비 중에는 이동 화살표를 비활성화한다.

## 방

- 공개방과 비밀방 지원
- 비밀방은 홈/검색에 노출되지만 입장 시 PIN을 요구한다.
- 방장/부방장 권한:
  - 방 편집
  - 가입신청 승인/거절
  - 멤버 관리
  - 채팅 금지
  - 강퇴/차단
- 방장은 방 삭제 가능
- 내가 속한 방은 신고할 수 없도록 막는다.

## 스토리

- 방 멤버 공개/전체 공개 구분
- 성인방 스토리는 멤버 공개만 허용
- 메인 공개 스토리는 12개씩 로딩
- 랜덤 정렬은 3시간 단위로 재배열
- 스토리/댓글 작성자는 방 프로필 정보가 즉시 반영되어야 한다.

## 신고/차단

- 방, 멤버, 스토리 신고
- 신고 전 확인 팝업 표시
- 신고 완료 팝업 표시
- 내가 신고한 방은 목록/프로모션/탑스페이스/스토리에서 숨김
- 단, 내가 참여 중인 방은 신고 불가

## 포인트와 상품

- 출석 체크: 1시간 주기, 20P
- 광고 보고 포인트 더 받기: 출석 체크 비활성 기간마다 1회, 10P
- 색연필/말풍선: 포인트 구매, 7일 유효
- 커스텀 색상: 최대 10개 활성 슬롯, 유효기간 만료 또는 삭제 시 슬롯 반환
- 앱 테마, 광고 제거, 포인트 충전은 인앱 결제

## 광고

- 보상형 광고: 포인트 보상
- 배너 광고:
  - 메인 4개 탭 바텀 네비게이터 위
  - 채팅 입력창과 키보드 사이
  - 스토리 본문과 댓글 사이
- 광고 없는 계정이면 광고와 광고 자리 여백을 모두 제거한다.

## 심사 기준

- ATT를 쓰면 앱 시작 초기에 권한 요청을 명확히 띄운다.
- 추적하지 않는다면 App Store Connect 개인정보 답변에서 추적을 제거한다.
- Age Rating의 Parental Controls/Age Assurance는 실제 기능이 없으면 None으로 둔다.
- UGC 앱으로서 신고, 차단, 필터링, 24시간 내 운영자 검토 정책을 명확히 설명한다.
