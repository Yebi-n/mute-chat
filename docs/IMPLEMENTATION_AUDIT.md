# Implementation Audit

Updated: 2026-07-07

이 문서는 과거 구현 감사 기록의 보관본입니다. 이전 파일은 인코딩이 깨져 최신 인수인계 문서로 사용하기 어렵기 때문에, 현재 기준 문서로 라우팅합니다.

## Current Sources Of Truth

- `DOCS_INDEX.md`: 문서 전체 인덱스와 우선순위
- `HANDOFF_CODEX.md`: 로컬 폴더, 서버, 배포, 운영 인수인계
- `ACTION_PLAN.md`: 현재 남은 작업과 우선순위
- `PRODUCT_SPEC.md`: 제품 기능 기준
- `DATA_MODEL.md`: 서버 데이터 모델 참고
- `STORE_COMPLIANCE.md`: 심사/정책 기준

## Rule

이 문서와 최신 기준 문서가 충돌하면 최신 기준 문서를 따른다.
