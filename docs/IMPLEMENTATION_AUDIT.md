# 뮤트 구현 전수조사

조사 기준: 2026-06-13 `App.tsx`, `src`, Supabase 원격 마이그레이션과 UI 자동 시나리오.

## 현재 서버 연결 완료

- Supabase 세션 복원, 전화번호 OTP, 로그아웃
- 방 목록, 내 참여 방, 방 생성, 가입 신청
- 성인 인증 상태 조회와 성인 방 RLS 차단
- 공개/비밀방, 선택형 6자리 PIN, 1분 방 생성 쿨타임
- 텍스트 메시지, 답장, 서버 채팅 검색
- 이미지/GIF 선택, 압축, 최대 5장, 비공개 Storage 업로드, MIME/용량 검증
- 방 대표 이미지 크롭, 압축, 비공개 Storage 업로드
- `user_id` 기반 강퇴, 재가입 차단, 차단 해제와 감사 로그
- 방 고정 설정, 최근 메시지 기준 정렬
- 공개/방 전용 스토리 데이터 구조
- 푸시 토큰, 발송 큐, 보안 적용 Edge Function
- 신고, 사용자 차단, 약관 동의, 계정 탈퇴 요청 데이터 구조

## UI까지 동작

- 내 채팅 우선 진입, 홈/스토리/내 정보 탭
- 프로모션 랭킹, Top/Hot, 검색 전 빈 상태
- 방 설명, 3열 멤버, 방별 프로필과 사진 확대
- 채팅 검색, 긴 메시지 전체보기, 읽음 구분선, 복사와 사진 저장
- 말풍선/텍스트/배경 테마, 하트, 비밀 쪽지 화면
- 알림 드로어 읽음 처리와 관련 화면 이동
- 길게 눌러 방 상단 고정
- 가입 신청 목록, 부방장/강퇴/차단 관리 화면
- 방 생성 분류, 1~80명 스텝퍼, 성인 분류 잠금

## 서버 명령 연결이 남은 버튼

- 가입 신청 승인/거절
- 부방장 지정/해제
- 방 삭제
- 하트 보내기와 비밀 쪽지
- 스토리 작성/수정/삭제/댓글
- 탑스페이스 포인트 차감과 노출 실행
- 방별/전체 알림 설정과 읽음 상태 영속화
- 신고 사유 입력과 실제 신고 접수

## 화면 또는 외부 계약이 남은 항목

- 포인트 충전, 내역, 광고 보상, 인앱 결제 영수증 검증과 복원
- 실제 국내 본인확인 및 성인 인증 사업자 연동
- 인증 전화번호 변경
- 개인정보처리방침/이용약관 공개 웹페이지
- 피드백 메일 연결
- 계정 탈퇴 최종 확인과 삭제 작업
- 운영자 웹 콘솔과 운영자 MFA

## 출시 전 필수 운영 작업

- Supabase Cron에서 `send-push-outbox`를 Vault의 service-role 키로 호출
- Expo Push receipt 처리와 만료 토큰 비활성화
- 메시지 실시간 구독, 페이지네이션, 오프라인 재전송
- Storage 객체 정리 작업과 썸네일 파이프라인
- 신고/차단/삭제 대응 SLA와 콘텐츠 보존 정책
- Apple/Google 심사용 성인 인증 계정과 검수 동선
- 개인정보 문서, 사업자/통신판매업, 결제 및 환불 정책 확정

세부 출시 기준은 `docs/STORE_COMPLIANCE.md`, 푸시 운영은
`docs/PUSH_OPERATIONS.md`를 따른다.
