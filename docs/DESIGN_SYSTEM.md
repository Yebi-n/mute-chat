# Design System

Updated: 2026-07-07

## Color Principles

- 기본 테마: 민트/그린 그라디언트.
- 화이트 테마: 헤더와 주요 버튼은 흰색 계열, 텍스트/아이콘은 `#222222` 계열로 시인성을 확보한다.
- 다크 테마: 배경은 `#222222` 계열을 기준으로 하고, 본문/공지/구분선은 어두운 배경에서 읽히는 회색/흰색 계층을 사용한다.
- 포인트, 하트, 역할 배지, 신고/차단 의미색은 테마색과 분리한다.
- 초록색 그림자는 쓰지 않고, 필요한 경우 회색 그림자를 사용한다.

## Layout Principles

- iPhone 중심 UI다. iPad 전용 스크린샷 요구를 피하기 위해 iPhone only 설정을 유지한다.
- 입력창은 키보드 위에 붙어야 하며, 광고 배너가 있는 경우 배너 높이만큼 먼저 공간을 예약해 레이아웃 점프를 줄인다.
- 광고 제거 계정은 광고 컴포넌트뿐 아니라 광고 예약 여백도 제거한다.
- 채팅방에서 다른 내부 페이지로 이동했다 돌아오면 기존 스크롤 위치를 유지한다.

## Component Rules

- 버튼은 기본적으로 그라디언트를 사용한다. 화이트/다크 테마는 시인성 우선으로 예외를 둔다.
- 신고 버튼은 실행 전 확인 팝업을 띄운다.
- 방에 참여 중인 사용자는 해당 방을 신고할 수 없다.
- 더보기/햄버거/프로필 액션은 바깥 영역 터치 시 닫혀야 한다.
