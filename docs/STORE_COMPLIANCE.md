# 뮤트 iOS/Android 출시 준수 기준

기준일: 2026-06-12

이 문서는 스토어 정책과 국내 운영 위험을 제품·서버 설계에 반영하기 위한 실무
체크리스트다. 심사 통과를 보장하거나 법률 자문을 대신하지 않으며, 출시 직전 국내
변호사 또는 개인정보 전문가의 최종 검토를 받는다.

## 제품 정의

뮤트은 랜덤 익명 채팅 앱이 아니다.

- 국내 휴대폰 본인확인을 완료한 계정만 가입한다.
- 사용자에게는 실명이 아니라 방마다 설정한 가명 프로필을 표시한다.
- 모든 방은 가입 신청과 방장·부방장 승인을 거친다.
- 무작위 매칭, 낯선 사람 자동 연결, 익명 전화·문자 기능을 제공하지 않는다.
- 운영자는 CI 기반 중복 가입 방지, 신고 처리, 계정 제재를 수행할 수 있다.

스토어에서는 `anonymous chat`보다
`verified, approval-based interest communities with room-specific profiles`로 설명한다.

## 성인 영역

`성인`은 음란물 또는 만남 주선 카테고리가 아니다. 성인 인증 사용자가 일상, 직장,
주류 등 성인 주제를 대화하는 별도 커뮤니티 영역이다.

- 포르노, 노골적인 성행위 묘사, 성매매·조건만남, 성적 서비스 알선은 금지한다.
- 미성년자 성적 대상화, 그루밍, 아동·청소년 성착취물은 즉시 차단한다.
- 비동의 촬영물, 성적 딥페이크, 사적 이미지 유포를 금지한다.
- 성인 방은 미인증 사용자의 목록, 검색, 프로필, 알림, 딥링크에서 모두 제외한다.
- 본인확인기관 결과를 서버에서 검증하고 만 19세 이상일 때만 인증 시각을 기록한다.
- 원본 CI/DI, 실명, 생년월일은 저장하지 않는다. 서버 HMAC CI와 인증 시각만 저장한다.
- 성인 콘텐츠를 탑스페이스, Hot, 푸시, 앱 아이콘, 스토어 스크린샷에서 홍보하지 않는다.

초기 심사에서 안전한 운영을 입증할 수 없다면 성인 기능은 원격으로 숨기지 않고 해당
빌드에서 제외한다. 숨겨진 미고지 기능도 심사 위험이다.

## UGC 필수 기능

- 게시 전 이용약관·개인정보처리방침·커뮤니티 운영정책 동의
- 방, 프로필, 메시지, 스토리, 댓글별 신고
- 사용자 차단과 차단 해제
- 신고 접수 번호와 처리 상태
- 운영자 검토 큐, 제재, 감사 로그
- 금칙어·링크·반복 메시지·이미지 기본 필터
- 미성년자 안전, 폭력, 자해 신고의 긴급 우선순위
- 운영 문의 이메일과 개인정보 문의 채널
- 인앱 계정 탈퇴와 웹 기반 탈퇴 요청 경로

## 데이터와 인증

- NICE, KCB, 다날 등 국내 본인확인기관과 서버 콜백으로 연결한다.
- 공급자의 성공 화면만 신뢰하지 않고 서버가 거래 ID, 위변조 여부, 만료, 재사용을 검증한다.
- 앱에는 본인확인 공급자의 비밀키를 포함하지 않는다.
- 인증 결과는 1회용 nonce와 사용자 세션에 묶는다.
- 관리자 계정은 일반 사용자 계정과 분리하고 MFA와 행동 감사를 적용한다.
- 탈퇴 요청 시 7일 유예 후 Auth 사용자, 프로필, 푸시 토큰을 삭제·익명화한다.
- 결제, 분쟁, 신고 증거처럼 법적 보존이 필요한 자료만 목적과 기간을 구분해 보존한다.

## 결제와 광고

- 포인트, 테마, 색상, 탑스페이스는 StoreKit과 Google Play Billing을 사용한다.
- 결제 영수증은 서버에서 검증하고 중복 방지 키와 함께 원장에 기록한다.
- 구매 포인트는 임의 만료시키지 않는다.
- 복원 가능한 상품은 구매 복원 기능을 제공한다.
- 광고 보상은 광고사의 서버 검증 콜백 이후에만 지급한다.
- 부적절하거나 연령에 맞지 않는 광고를 신고할 수 있게 한다.

## Apple 제출

- 연령 등급은 최소 17+로 보수적으로 응답한다.
- 일반 계정과 성인인증 완료 리뷰 계정을 제공한다.
- 국내 본인확인을 리뷰어가 수행할 수 없다면 심사용 계정 또는 완전한 데모 모드를 제공한다.
- 리뷰 노트에 방 가입 승인, 신고, 차단, 계정 삭제, 성인 게이트 위치를 적는다.
- 서버와 신고 운영 연락처를 심사 기간 동안 실제로 동작시킨다.
- 스크린샷과 설명에 성적 키워드, 자극적 방 이름, 실제 사용자 정보를 넣지 않는다.
- 인앱 결제 상품과 구매 복원을 심사 빌드에서 확인 가능하게 한다.

## Google Play 제출

- UGC 정책 설문, 데이터 보안, 콘텐츠 등급을 실제 기능에 맞게 응답한다.
- 채팅 UGC, 사용자 간 상호작용, 성인 영역 존재를 숨기지 않는다.
- 성인 영역은 기본 비노출이며 본인·연령 확인 후에만 접근하게 한다.
- 앱 안과 외부 웹페이지 모두에서 계정 삭제를 요청할 수 있게 한다.
- 개인정보처리방침 URL은 공개되고 로그인 없이 열려야 한다.
- 테스트 계정과 본인확인 우회용 리뷰 계정을 Play Console에 제공한다.

## 운영 준비

- 미성년자 안전·현실적 위해 신고는 즉시 알림, 일반 신고는 24시간 내 1차 확인
- 운영자 근무 공백 시 성인 방 신규 생성과 이미지 업로드 제한
- 신고 누적 방은 Hot/TopSpace 노출 제외
- 신고 누적 계정은 쪽지, 이미지, 새 방 생성 단계적 제한
- CS 이메일, 개인정보 보호 책임자, 사업자 정보, 통신판매업 정보 게시
- 개인정보 유출, 불법촬영물, 아동 안전 신고 대응 절차와 연락망 문서화

## 현재 출시 차단 항목

- 국내 본인확인기관 계약과 콜백 Edge Function
- 실제 약관·개인정보처리방침·커뮤니티 정책 URL
- 신고 입력 화면과 서버 연결
- 차단을 채팅·쪽지·프로필 조회에 반영하는 로직
- 운영자 신고 검토 콘솔과 제재 RPC
- 계정 탈퇴 완료 작업과 외부 탈퇴 웹페이지
- 이미지·텍스트 유해 콘텐츠 필터
- StoreKit/Play Billing과 서버 영수증 검증
- 심사용 일반/성인인증 계정

## 공식 정책 기준

- Apple App Review Guidelines 1.1, 1.2, 2.1, 2.3, 3.1.1, 5.1
- Google Play 사용자 제작 콘텐츠, 부적절한 콘텐츠, 계정 삭제, 데이터 보안 정책
- 대한민국 개인정보보호법, 청소년보호법, 전기통신사업법 및 관련 하위 규정
