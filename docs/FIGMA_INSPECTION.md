# Figma 구현 메모

## 제품과 로고
- 제품명은 **뮤트**이다(Figma 파일명 `뮤트`, 페이지 `Page 1` / `0:1`).
- 로고는 글자 없이, 뾰족한 돛·건물 형태 3개와 겹친 물결을 결합한 심벌이다. 스플래시(`1:1453`)에서는 청록→초록 그라데이션 배경 중앙의 흰색 심벌, 홈 헤더(`1:1739`)와 하단 GNB(`16:418`)에서는 흰 바탕의 청록·초록 그라데이션 심벌로 보인다.

## 홈 목록
- 홈(`1:1458`)은 상단 헤더 48px, 목록, 하단 4아이콘 GNB 구조다.
- 섹션 라벨은 정확히 `Top`(`16:522`), `Hot`(`16:543`)이다. `Top` 우측에는 `랭킹`(`16:524`)과 꺾쇠가 있다.
- `Top`은 1개, `Hot`은 세로 반복 목록이다. 각 행은 92px이며 왼쪽 68px 원형 회색 방 이미지, 오른쪽에 `방제`, 인원 `3/8`, 우측 `3분 전`, 한 줄 말줄임 설명 `방에 대한 설명입니다. ...`를 둔다.
- 홈 상단(`1:1739`): 왼쪽 로고는 x=15, 48×44; 오른쪽 검색은 42×42, 추가 `+`는 42×42이며 묶음이 x=276에 있다.
- 하단 GNB(`16:393`) 아이콘 순서는 로고/홈, 채팅, 문서, 설정이다.

## 상단 바
- 채팅(`18:1290`): 왼쪽 뒤로가기, `방제`(`18:1303`), `10명`(`18:1304`); 오른쪽 햄버거(`18:1309`).
- 공간 프로필(`20:1921`): 왼쪽 뒤로가기(`20:1923`), 잠금(`20:2237`), `방제`(`20:1926`), `10명`(`20:1927`); 오른쪽 설정(`20:2088`).
- 공통 배경은 `#82B9C1`→`#5DBB8C` 가로 그라데이션이며 아이콘과 제목은 흰색이다.

## 오른쪽 드로어
- 햄버거 화면은 `#Chat_main_hambuger`(`19:1428`). 드로어(`19:1523`)는 화면 오른쪽 x=49부터 326px 폭으로 열리고, 흰 배경과 왼쪽 방향 그림자를 사용한다.
- 상단에는 기본 프로필 심벌, 편집 연필 배지, `닉네임`(`19:1592`), `자기 소개가 들어가는 공간입니다. ...`(`19:1585`)가 있다.
- 메뉴의 정확한 순서는 `알림 설정`(`19:1661`, 우측 토글), `가입 신청 목록`(`19:1559`), `탑스페이스`(`19:1564`), `멤버 및 방 보기`(`19:1571`), `스토리 보기`(`19:1604`)다.

## 기본 이미지
- 기본 사용자 프로필은 연회색 원 안의 흰 머리·어깨 실루엣이며 우하단에 작은 원형 연필 배지가 붙는다(`17:1098`, `17:1100`). 채팅/멤버 축약형은 이미지 없는 `#E7E7E7` 원이다(`18:1324`, `20:2195`).
- 기본 방 이미지는 생성 화면(`38:615`)의 4:3 연회색 직사각형, 12px 모서리, 중앙 흰 카메라 아이콘이다. 홈 목록 기본값은 68px 회색 원(`16:528`).
- 실제 방 대표 이미지는 공간 프로필(`20:2084`)의 375×282 커버 사진이다. 어두운 세로 면과 밝은 벽 경계에 숫자 `7`이 적힌 거친 돌이 중앙에 보인다.

## 공간 소개와 가입 요청
- 공간 프로필(`20:1919`)은 탭 `프로필`(`20:2076`, 선택 밑줄) / `스토리`(`20:2079`) 뒤에 커버 이미지가 온다.
- 커버 하단 반투명 검정 정보 칩에는 `2025.12.30.`(`20:2105`)과 `3명`(`20:2110`)이 표시된다.
- 소개 영역(`20:2126`)은 `#해시태그1  #해시태그2`를 그라데이션 강조하고, 이어서 `방에 대한 소개글입니다.`를 여러 줄 표시한다. 아래 `멤버`(`20:2141`) 영역은 방장 83px 원형 프로필에 그라데이션 테두리와 왕관 배지(`20:2165`), `닉네임`, 자기소개 카드, 이후 75px 원형 멤버 그리드를 사용한다.
- `20:1919` 자체는 가입 완료 상태라 가입 버튼이 없다. 미가입 변형 `#Space_profile_가입정보없음`(`21:431`)은 우하단 70px 그라데이션 원형 로그인 버튼(`21:794`)을 띄운다.
- 버튼을 누르면 가입 신청 화면(`17:934`)으로 이동한다. 제목은 `[방제] 가입 신청`(`17:1073`), 입력 라벨은 `이름` / `자기 소개`, 자리표시는 `가입할 이름을 입력해주세요.` / `자기 소개를 입력해주세요.`, 카운터는 `0/13` / `0/60`, 제출 문구는 `가입하고 싶어요`다. 필수값 전에는 버튼이 회색 비활성 상태다.

## 채팅방
- 채팅방(`18:1157`)은 상단 바, 흰 메시지 목록(`18:1315`), 하단 입력 바(`19:1405`) 구조다.
- 상대 메시지는 왼쪽: 46px 회색 원형 프로필, `닉네임`, 연회색 `#F5F5F5` 12px 둥근 말풍선. 연속 메시지는 프로필/이름을 생략한다.
- 내 메시지는 오른쪽 정렬이며 시간 `오후 9:26`을 말풍선 왼쪽에 둔다. 이미지 메시지는 140×140 회색 12px 둥근 카드다.
- 시스템 알림은 위아래 구분선과 느낌표 아이콘을 사용하며 정확한 문구는 `닉네임님이 가입을 요청했습니다.`, `닉네임님이 닉네임님에게 하트를 보냈습니다.`, `닉네임님이 방제에서 탈퇴했습니다.`다.
- 하단에는 추가 `+`, 브러시, 자리표시 `메시지를 입력해주세요.`, 청록→초록 원형 전송 버튼 순으로 배치한다.
