# Figma Redesign Notes

Updated: 2026-07-07

이 문서는 과거 Figma/UI 참고 기록의 보관본입니다. 최신 UI 기준은 코드와 아래 문서를 우선합니다.

## Current Sources Of Truth

- `PRODUCT_SPEC.md`: 주요 화면과 UX 기준
- `DESIGN_SYSTEM.md`: 디자인 시스템 참고
- `CHAT_MESSAGE_RULES.md`: 채팅 UI/메시지 규칙
- `MONETIZATION_SETUP.md`: 아이템샵/테마/광고 UI 기준

## Rule

과거 Figma 메모와 현재 앱 구현이 충돌하면 현재 앱 구현과 `PRODUCT_SPEC.md`를 기준으로 한다.
