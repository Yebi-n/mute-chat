# Android 웹 콘솔 진행표

최종 업데이트: 2026-07-07

## 목적

Google Play Console에서 웹으로 바로 처리할 수 있는 항목을 먼저 진행한다. iOS 설정은 건드리지 않는다.

## 앱 기본값

- 앱 이름: 뮤트
- 패키지명: `app.mute.chat`
- 기본 언어: 한국어
- 앱 유형: 앱
- 가격: 무료
- 개인정보 처리방침: `https://service-introduction-theta.vercel.app/privacy/`
- 운영/문의 이메일: `muteappcontact@gmail.com`
- 카테고리 후보: 소셜

## Play Console에서 바로 입력 가능한 항목

### 앱 액세스

- 로그인 필요: 예
- 심사용 계정: 별도 테스트 계정 필요
- 비고: 전화번호 인증이 필요한 계정이면 심사자가 접근하기 어렵다. 이메일/관리자 테스트 계정 또는 인증 우회가 가능한 심사용 계정을 쓰는 것이 안전하다.

### 광고

- 광고 포함 여부: 예
- 광고 SDK: Google AdMob
- 광고 형식: 보상형 광고, 배너 광고

### 정부 앱

- 정부 앱 여부: 아니요

### 금융 기능

- 금융 기능 여부: 아니요
- 포인트/인앱 구매는 앱 내 디지털 재화 구매이며 금융 서비스로 보지 않는다.

### 건강

- 건강/의료 기능 여부: 아니요

### 사용자 생성 콘텐츠

- 사용자 생성 콘텐츠 있음: 예
- 유형: 채팅, 스토리, 댓글, 프로필, 이미지
- 신고 기능: 있음
- 차단/강퇴 기능: 있음
- 운영자 검토: 있음
- 조치 기준: 신고 접수 후 운영자가 검토하고, 위반 콘텐츠 삭제 및 사용자 제한을 수행한다.

### 타겟층

- 성인 기능은 iOS 심사 빌드에서 노출하지 않는다.
- Android도 인증 전에는 성인 카테고리를 노출하지 않는 원칙을 유지한다.
- 초기 심사는 일반 사용자 대상 기능 중심으로 진행한다.

## 수동 확인이 필요한 항목

### 심사용 로그인 계정

필요 정보:

- 로그인 ID
- 비밀번호
- 인증 우회 여부
- 심사자가 확인할 수 있는 방/스토리 존재 여부

### 스토어 등록정보

필요 정보:

- 짧은 설명
- 자세한 설명
- 앱 아이콘
- 기능 그래픽
- 휴대전화 스크린샷
- 필요 시 태블릿 스크린샷

### 데이터 보안

선언 대상 후보:

- 전화번호
- 사용자 ID
- 프로필 이름/소개/이미지
- 채팅, 스토리, 댓글, 쪽지
- 신고 정보
- 구매 내역
- 포인트 내역
- 광고 ID 또는 광고 관련 데이터
- 앱 활동 및 진단 정보

주의:

- 실제 수집/전송과 다르게 선언하면 심사 리스크가 크다.
- AdMob을 사용하는 경우 광고 ID 및 광고 데이터 항목을 반드시 확인한다.

## 외부 콘솔 산출물이 필요한 항목

### Firebase / FCM

- Firebase Android 앱 등록 필요
- `google-services.json` 필요
- FCM V1 서비스 계정 키 필요
- EAS Credentials에 연결 필요

### AdMob Android

- Android AdMob 앱 ID 필요
- Android 보상형 광고 단위 ID 필요
- Android 배너 광고 단위 ID 필요

### Google Play Billing

- 인앱 상품 생성 필요
- 구독 상품 생성 필요
- Google Play Developer API 서비스 계정 필요
- Supabase 서버 검증 로직 필요

## 오늘 웹에서 우선 처리할 순서

1. Play Console 앱 대시보드 열기
2. 앱 콘텐츠 항목 중 정부 앱/금융/건강/광고 여부 입력
3. 앱 액세스는 심사용 계정이 확정되면 입력
4. 데이터 보안은 실제 수집 항목 최종 확인 후 입력
5. 스토어 등록정보는 이미지/문구 확정 후 입력

## 2026-07-07 현재 열어둔 Play Console 섹션

- 앱 콘텐츠: 정부 앱, 금융 기능, 건강, 광고, 데이터 보안, 앱 액세스, 콘텐츠 등급 입력용
- 기본 스토어 등록정보: 설명, 아이콘, 스크린샷, 기능 그래픽 입력용
- 내부 테스트: 첫 Android AAB 업로드 및 설치 테스트용
- 릴리즈 개요: 트랙별 출시 상태 확인용

## 콘솔 입력값 빠른 기준

### 바로 저장 가능

- 광고 포함: 예
- 광고 네트워크: Google AdMob
- 정부 앱: 아니요
- 금융 기능: 아니요
- 건강/의료 기능: 아니요
- 뉴스 앱: 아니요
- 코로나19 접촉 추적/상태 앱: 아니요

### 사용자 확인 후 저장

- 앱 액세스: 심사용 로그인 계정이 확정된 뒤 입력
- 데이터 보안: 실제 Android 수집 항목과 AdMob/푸시/결제 항목을 최종 대조한 뒤 입력
- 콘텐츠 등급: 성인 카테고리 비노출 정책과 UGC 신고/차단 기능 기준으로 응답
- 스토어 등록정보: Android용 스크린샷/기능 그래픽 확정 후 입력

## 심사용 계정 기준

심사용 계정은 다음 조건을 만족해야 한다.

- 심사자가 SMS 인증 없이 로그인 가능하거나, 인증 절차가 사전에 완료되어 있어야 한다.
- 최소 1개 방, 1개 스토리, 신고/차단 진입점을 확인할 수 있어야 한다.
- 성인 카테고리는 인증 전 노출되지 않아야 한다.
- 앱 내 구매 기능은 실제 결제 대신 테스트 환경에서 동작 가능한 상태여야 한다.

## 보류 기준

다음 항목은 자동 저장하지 않고 사용자 확인 후 진행한다.

- 심사용 로그인 계정 입력
- 데이터 보안 최종 제출
- 콘텐츠 등급 최종 제출
- 스토어 등록정보 게시 저장
- 앱 출시/심사 제출
