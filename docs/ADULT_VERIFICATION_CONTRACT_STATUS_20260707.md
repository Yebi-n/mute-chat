## KG이니시스 메일 확정 사항

KG이니시스 통합인증서비스 메일에서 확인한 운영 기준:

- 신청 이후 사용까지 약 3주 소요 예정
- 계약 진행과 첨부파일 심사자료 회신이 필요
- 계약 이후 인증서 심사 진행
- 계약 방식은 기존 KG이니시스 PG 사용 여부에 따라 달라짐
- 문의/회신 담당: `pdev@kggroup.co.kr`

## 계약 방식

### KG이니시스 PG 미사용 신규 가맹점

구비서류를 우편 송부해야 한다.

- 사업자등록증 또는 사업자등록증명원
- 개인사업자: 대표자 개인 인감증명서 원본
- 통장 사본
- 이용계약서 원본 2부
- 이용계약서에는 인감 날인 필수
- 통장 사본을 제외한 서류는 3개월 이내 발급본 요구 가능

보낼 곳:

```text
서울특별시 중구 통일로 92 KG타워 15층
상품전략팀 전희진 매니저
02-3430-5713
```

### KG이니시스 PG 사용 MID 보유 가맹점

전자계약 경로를 사용할 수 있다.

```text
iniweb.inicis.com 로그인
> 변경/추가
> 1.2.3 특약&부가서비스 계약
> 6. 통합인증서비스
```

필요 작업:

- 사이트 URL 입력
- 서비스 선택
- 심사자료 업로드
- 신청하기

개인사업자는 대표자 간편인증 또는 사업자범용 공동인증서가 필요하다.

## 인증 수단

PortOne 안내 기준 사용 가능한 인증 수단:

- 네이버
- TOSS
- 카카오
- 금융인증서
- 신한인증서
- PASS 인증서
- KB모바일인증서
- 삼성패스 인증서

주의:

- 휴대폰 번호 SMS 인증 방식은 지원 안내 대상이 아니다.
- PASS 휴대폰 본인확인이 아니라 `PASS 인증서` 수단으로 이해해야 한다.
- 카카오 인증에서 CI 제공이 필요하면 별도 요청/서류가 필요할 수 있다.

## PG 계약과 성인인증 계약 구분

현재 포트원/PG 메일이 섞여 있으므로 아래처럼 구분한다.

- 포인트 충전, 웹 결제, 카드 결제: PG/전자결제 계약 영역
- 성인 여부 확인, 본인확인, CI 확보: KG이니시스 통합인증서비스 영역
- iOS 인앱결제: Apple IAP 영역

성인인증 서버 연동은 PG 카드 심사 완료와 별개로 진행할 수 있지만, KG 통합인증 운영 키와 콜백 URL 등록은 반드시 필요하다.

## PDF/FAQ 추가 판독 기준

사용자가 제공한 `통합인증서비스 심사자료 제출서`와 `계약 FAQ` 기준으로 아래를 최신 판단으로 둔다.

### 보증보험 판단

- 제공된 통합인증서비스 FAQ에는 보증보험 가입이 필수라는 문구가 없다.
- FAQ는 PG 미이용 사업자의 경우 `구비서류 + 계약서 원본 2부 우편 전달`을 요구한다.
- 계약서 제6조 5번 4번의 계약일자는 `PG 계약일자`이며, PG 미계약이면 공란 제출하라고 안내되어 있다.
- 따라서 현재 목적이 `성인인증/본인확인 단독 사용`이면 보증보험 절차는 보류한다.
- 다만 KG이니시스 담당자에게 `PG 계약 없이 통합인증서비스만 이용하는 경우 보증보험이 불필요한지`를 회신으로 확정받는다.

담당자 확인 문구:

```text
안녕하세요. 뮤트 서비스 담당자입니다.

현재 PG 결제 계약이 아니라 통합인증서비스를 통한 본인확인/성인인증만 이용하려고 합니다.
첨부 FAQ 기준으로는 PG 미계약 시 계약서 원본 2부와 구비서류를 우편 제출하고, PG 계약일자는 공란으로 두는 것으로 이해했습니다.

통합인증서비스 단독 이용의 경우 보증보험 가입이 필요하지 않은지 확인 부탁드립니다.
```

### 심사자료 제출서 작성안

| 항목 | 작성 기준 |
| --- | --- |
| 이용기관 홈페이지 URL | 앱스토어 공개 전이면 앱 화면 정리 PPT + 사업자 대표 홈페이지 또는 서비스 소개 URL. 앱스토어 공개 후에는 App Store URL 사용 가능 |
| 이용기관 사업자명/서비스명 | 사업자 상호를 `뮤트`로 변경 완료했으면 `뮤트 / 뮤트`로 작성 |
| 인증서 적용 경로 | `외부 성인인증 웹페이지 로그인 후 성인 카테고리 접근 권한 확인`, `비밀번호 찾기/계정 확인은 추후 본인확인 연동 가능` |
| 오픈 일정 | 확정 전이면 `2026년 7월 중 예정` 또는 `추후 오픈` |
| 개인정보처리방침 URL | CI 수집 문구가 포함된 개인정보 처리방침 URL 제출 |
| 로고 첨부 | PNG 2장 필요: `168x168`, `가로 1300 이하 x 세로 192 고정` |
| 담당자 정보 | 사용자 실 담당자명, 연락처, 이메일 기입 |

### 개인정보처리방침 CI 문구

카카오 인증서 심사를 포함하려면 개인정보 처리방침의 개인정보 수집 항목에 `CI`가 명시되어야 한다.

권장 문구:

```text
본인확인 및 성인인증 시 이름, 생년월일, 성별, 휴대전화번호, 인증기관, 인증일시, 성인 여부, 암호화된 이용자 확인값(CI)을 수집할 수 있습니다.
CI는 계정 중복 확인, 본인확인 결과 관리, 성인인증 상태 관리 목적상 해시 또는 암호화된 형태로 저장될 수 있습니다.
```

현재 개인정보 처리방침 HTML/Markdown에 위 문구가 없으면 심사자료 제출 전 반영한다. CI 문구가 없으면 카카오 인증서는 노출되지 않을 수 있다.

### 로고 제출물

필수 PNG:

- `mute-logo-168.png`: 168 x 168 px
- `mute-logo-wide-192.png`: width <= 1300 px, height 192 px

기존 앱 아이콘/스플래시 로고를 기준으로 제작하되, 인증서 화면에서 작게 보일 수 있으므로 배경 대비와 여백을 확인한다.

### 계약 진행 메모

- MID는 계약 완료 후 발급된다. 처음 계약이면 비워두는 것이 정상이다.
- 계약서 2부는 KG이니시스 보관 1부, 가맹점 보관 1부 용도다.
- 개인사업자가 인감 대신 서명으로 진행하면 `본인확인사실서` 원본을 요구할 수 있다.
- 통장사본은 상점관리자 2차 인증용 계좌 뒷 5자리 확인에 사용된다.
- 인증서 개별 심사는 자료 전달일 기준 약 2주 이상 걸릴 수 있다.

아래 질문은 계약 진행 전에 반드시 확인한다.

```text

확인 부탁드립니다.

1. 현재 신청 건이 통합인증서비스 운영 계약으로 정상 접수되어 있는지
```

## 서버 연동 대기 조건

아래 값이 발급되기 전까지는 운영 성인인증을 완료 처리하지 않는다.

- PortOne Store ID 또는 KG 상점 식별자
- 통합인증 채널 키 또는 서비스 ID
- API Secret
- 콜백 검증 Secret 또는 서명 검증 방식
- 운영/테스트 환경 구분
- 콜백 URL 등록 완료 여부
- 인증 응답에 포함되는 성인 여부 필드
- CI 또는 대체 식별자 제공 여부

## Supabase Secret 예정 이름

PortOne 경유를 기본으로 둔다.

```powershell
npx.cmd supabase secrets set PORTONE_STORE_ID="..."
npx.cmd supabase secrets set PORTONE_IDENTITY_CHANNEL_KEY="..."
npx.cmd supabase secrets set PORTONE_API_SECRET="..."
npx.cmd supabase secrets set ADULT_VERIFY_PROVIDER="portone_kg_inicis"
```

KG 직접 연동으로 바뀌면 아래 이름을 추가로 사용한다.

```powershell
npx.cmd supabase secrets set KG_INICIS_SITE_CODE="..."
npx.cmd supabase secrets set KG_INICIS_API_KEY="..."
npx.cmd supabase secrets set KG_INICIS_API_SECRET="..."
```

## 앱 정책 유지

### iOS

- iOS 앱 내부에 성인 탭을 노출하지 않는다.
- iOS 앱 내부에 성인인증 또는 외부 웹 이동 안내를 노출하지 않는다.
- 외부 성인인증 웹은 앱 심사 메타데이터에 직접 우회 안내로 쓰지 않는다.

### Android

- Android는 별도 빌드에서 성인인증 완료 계정만 성인 탭을 노출한다.
- 미인증 계정에는 성인방/성인 스토리/성인 프로모션을 목록에서 숨긴다.
- 방 생성 화면에서는 인증 전 성인 카테고리를 비활성화한다.
