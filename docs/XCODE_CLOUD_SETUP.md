# Xcode Cloud Setup

## Current Decision

EAS iOS free build quota is exhausted until 2026-07-01. Mute should move iOS native builds to Xcode Cloud to use Apple Developer Program included compute time.

## Why This Order

The current Windows machine cannot generate the iOS native project with `expo prebuild --platform ios`; Expo requires macOS or Linux for that step. Therefore:

1. Push this repository to GitHub.
2. Run the GitHub Actions workflow `Generate iOS project` once.
3. The workflow generates and commits the `ios/` folder from Linux.
4. Connect the GitHub repository to Xcode Cloud.
5. Configure Xcode Cloud to build the generated `ios/mutechat.xcworkspace` or the generated workspace name shown in the repo.

This separates native project generation from Xcode Cloud signing/building and avoids consuming EAS build quota.

## GitHub Setup

This repository currently has no remote configured. Create a private GitHub repository, then push:

```powershell
cd C:\Users\trudy\mute-chat
git remote add origin https://github.com/<owner>/<repo>.git
git add .
git commit -m "Prepare iOS native build pipeline"
git push -u origin main
```

If the current branch is not `main`, either push the current branch or rename it before pushing.

## Generate iOS Project

In GitHub:

1. Open the repository.
2. Go to `Actions`.
3. Select `Generate iOS project`.
4. Run workflow.
5. Confirm the workflow committed an `ios/` directory.

## Xcode Cloud Setup

In App Store Connect:

1. Open app `뮤트`.
2. Go to `Xcode Cloud`.
3. Connect the GitHub repository.
4. Select the generated iOS workspace under `ios/`.
5. Use scheme generated by Expo.
6. Set workflow action to Archive.
7. Set signing to Apple managed signing for bundle ID `app.mute.chat`.
8. Set post-archive distribution to TestFlight.

The repo includes `.ci_scripts/ci_post_clone.sh`; Xcode Cloud runs it after checkout. It installs npm dependencies and runs `pod install`.

## Secrets

Do not commit:

- `.env`
- Apple `.p8`
- certificates
- provisioning profiles
- keystores
- service-role keys

Supabase Apple IAP secrets are already configured in Supabase, not in the repository.

## When To Use EAS Again

Use EAS only as fallback:

- Xcode Cloud is unavailable.
- urgent build is needed.
- Xcode Cloud workflow is broken and cannot be fixed quickly.

For JavaScript-only fixes after a binary with `expo-updates` is introduced, use OTA updates instead of native builds.
