# 뮤트 기능 확장 명세

기준일: 2026-06-12

이 문서는 2026년 6월 추가 요청사항의 구현 기준과 플랫폼 제약을 기록한다.

## 1. 멤버 강퇴와 차단

- 방장과 부방장은 활성 멤버를 강퇴할 수 있다.
- 방을 자발적으로 나간 멤버도 과거 멤버 목록에서 `user_id`로 찾아 재가입 차단할 수 있다.
- 차단은 프로필 이름이 아니라 변경되지 않는 `user_id`를 기준으로 저장한다.
- 차단된 사용자는 방 조회, 가입 신청, 초대, 재입장이 제한된다.
- 방장만 차단 해제할 수 있다.
- 방장 본인과 다른 방장은 강퇴·차단할 수 없다.
- 모든 강퇴, 차단, 해제는 행위자와 시각을 감사 로그로 남긴다.

## 2. 채팅 답장

- 메시지를 길게 누르면 `답장`, `복사`, `신고` 메뉴가 열린다.
- 답장은 작성창 위에 원문 작성자와 한 줄 미리보기를 표시한다.
- 답장 메시지에는 `reply_to_message_id`를 저장한다.
- 원문을 누르면 해당 메시지로 스크롤한다.
- 삭제된 원문은 `삭제된 메시지`로 표시한다.

## 3. 프로필 캡처 보호

- 프로필 상세와 프로필 사진 확대 화면에서 화면 캡처 보호를 요청한다.
- Android는 `FLAG_SECURE` 계열 기능으로 캡처·최근 앱 미리보기를 차단한다.
- iOS는 운영체제 정책상 스크린샷 자체를 완전히 차단할 수 없다. 캡처 감지와 화면
  녹화 시 민감 화면 가림을 적용한다.
- 웹에서는 기술적으로 캡처를 막을 수 없으므로 개인정보 최소 노출로 대응한다.

## 4. 긴 채팅 전체보기

- 일정 줄 수를 넘는 텍스트는 채팅 목록에서 접어 표시한다.
- `전체보기`를 누르면 해당 말풍선 안에서 펼쳐지고 `접기`로 되돌릴 수 있다.
- 검색 결과 이동 시 대상 메시지는 자동으로 펼친다.

## 5. GIF와 이미지

- GIF는 방 대표 이미지와 채팅 이미지에서만 허용한다.
- 프로필 사진은 정지 이미지로만 저장한다.
- GIF는 애니메이션 보존을 위해 이미지 변환기를 거치지 않고 원본 픽셀·MIME·용량을 검증한다.
- GIF 최대 크기: 10MB, 최대 픽셀: 12MP, 최대 긴 변 권장 1600px.
- 정지 이미지 최대 크기: 최적화 후 2MB, 긴 변 1600px.
- 채팅 이미지는 한 번에 최대 5개를 선택한다.
- 여러 장은 하나의 메시지 그룹으로 저장하고 2~5장 그리드로 표시한다.

## 6. 스토리 공개 범위

- `room`: 해당 방의 활성 멤버만 열람한다.
- `public`: 로그인 사용자 전체가 열람할 수 있다. 성인 방의 스토리는 전체 공개할 수 없다.
- 전체 공개 스토리는 메인 `스토리` 탭에서 최신순으로 표시한다.
- 메인 탭은 `내 채팅`, `홈`, `스토리`, `내 정보` 순서다.
- 공개 범위 변경, 편집, 삭제는 작성자 또는 방 운영자만 가능하다.

## 7. 채팅 검색

- 채팅 상단 검색 버튼으로 방 내부 검색 모드에 진입한다.
- 현재 프로토타입은 로컬 메시지를 검색하고, 서버 연결 후 PostgreSQL 검색 RPC를 사용한다.
- 결과는 최신순으로 표시하며 선택 시 해당 메시지로 이동한다.
- 비밀 쪽지는 발신자와 수신자만 검색 결과에 포함한다.

## 8. 푸시 알림

- 채팅 메시지, 답장, 비밀 쪽지, 가입 신청, 승인·거절, 운영 제재를 지원한다.
- 현재 열린 방의 일반 메시지 푸시는 보내지 않는다.
- 전체 알림과 방별 알림 설정을 서버에 저장한다.
- 푸시 payload에는 본문 전체나 민감정보를 넣지 않는다.
- APNs/FCM 토큰은 기기별로 저장하고 로그아웃·탈퇴 시 폐기한다.
- 서버 또는 Edge Function만 푸시를 발송한다.

## 9. 공개방과 비밀방

- 공개방은 검색과 홈 목록에 노출된다.
- 비밀방은 검색·홈·공개 스토리에서 제외한다.
- 비밀방은 선택적으로 숫자 PIN 6자리를 설정할 수 있다.
- PIN 원문은 저장하지 않고 서버에서 `pgcrypto` 해시로 검증한다.
- PIN 시도는 사용자·방·IP 단위로 제한한다.
- PIN을 통과해도 가입 승인 절차는 별도로 필요하다.

## 10. 채팅방 테마

- 방별 배경 테마를 선택한다.
- 기본 제공 테마와 구매 테마를 구분한다.
- 배경은 메시지 가독성과 대비 기준을 만족해야 한다.
- 움직이는 배경은 지원하지 않아 배터리와 렌더링 비용을 제한한다.

## 11. 채팅방 핀과 정렬

- 사용자는 참여 중인 방을 개인적으로 상단 고정할 수 있다.
- 고정 방끼리는 사용자가 지정한 순서, 나머지는 최신 메시지 시각 내림차순으로 정렬한다.
- 핀 설정은 다른 멤버에게 보이지 않는다.

## 12. 방 생성 쿨타임

- 계정당 방 생성은 1분에 한 번만 가능하다.
- 클라이언트 버튼 비활성화와 별개로 서버 RPC에서 강제한다.
- 운영 제재 계정은 더 긴 제한을 적용할 수 있다.

## 13. 사진 저장과 텍스트 복사

- 이미지 길게 누르기 메뉴에서 기기 사진함 저장을 제공한다.
- 저장 전 사진 접근 권한을 요청한다.
- 텍스트 길게 누르기 메뉴에서 클립보드 복사를 제공한다.
- 입력창은 운영체제 기본 붙여넣기를 허용한다.
- 비밀 쪽지와 신고 증거 화면은 저장·복사 정책을 별도로 제한할 수 있다.

## 출시 전 완료 조건

- 모든 명령의 서버 권한·RLS·속도 제한 검증
- 강퇴·차단·해제 감사 로그
- 비밀방 PIN 해시와 실패 제한
- GIF 실제 MIME 및 파일 시그니처 검사
- APNs/FCM 실기기 테스트
- Android 캡처 차단과 iOS 녹화 감지 실기기 테스트
- 신고·차단·계정 삭제와 함께 Apple/Google UGC 심사 시나리오 검증
