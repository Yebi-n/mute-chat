# 스크린샷 데모 모드

최종 업데이트: 2026-07-07

## 목적

App Store / Play Store 목업 캡처용으로 서버 데이터를 건드리지 않는 로컬 샘플 화면을 띄운다.

## 활성화

```text
EXPO_PUBLIC_SCREENSHOT_DEMO=1
```

## 비활성화

심사용/실사용 빌드에서는 반드시 제거하거나 `0`으로 둔다.

```text
EXPO_PUBLIC_SCREENSHOT_DEMO=0
```

## 포함 화면

- 여러 방이 있는 내 채팅
- 3인 채팅
- 답장, 하트, 비밀쪽지, 사진 메시지
- 색연필/말풍선 팔레트
- 방 설명/멤버
- 공개 스토리 목록
- 스토리 상세와 댓글

## 주의

- 로컬 샘플 데이터는 Supabase에 저장하지 않는다.
- 데모 모드 빌드를 심사나 실사용에 제출하면 안 된다.
- 캡처가 끝나면 Xcode Cloud 환경변수에서 즉시 비활성화한다.
