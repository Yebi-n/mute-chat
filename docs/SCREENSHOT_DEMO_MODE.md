# 촬영용 데모 모드

앱스토어 소개 이미지와 목업 제작을 위한 로컬 전용 데이터 모드입니다.
Supabase 운영 데이터에는 방, 메시지, 멤버, 스토리를 생성하지 않습니다.

## 활성화

촬영 전용 빌드의 환경변수에 아래 값을 추가합니다.

```text
EXPO_PUBLIC_SCREENSHOT_DEMO=1
```

Xcode Cloud에서는 촬영할 빌드의 Environment Variables에만 위 값을
추가합니다. 촬영이 끝나면 변수를 삭제하거나 값을 `0`으로 바꿉니다.

일반 빌드에서는 변수가 없으므로 운영 서버 데이터만 표시됩니다.

## 촬영 장면

1. `내 채팅`: 프로필 사진이 있는 6개 방, 비밀방, 최근 메시지, 0/1/3/7/12개 알림 뱃지
2. `오늘의 온도` 채팅방: 하루, 소라, 준의 온라인 대화와 답장, 하트, 비밀 쪽지, 사진 묶음
3. 채팅방 햄버거 메뉴의 `방 소개 및 스토리 보기`: 방 소개와 3명 프로필
4. 메인 `스토리`: 공개 스토리 3개
5. 첫 번째 공개 스토리: 본문 이미지와 댓글 2개
6. 채팅방의 색연필 버튼: 채팅 배경, 말풍선, 텍스트 팔레트

## 주의사항

- 촬영 모드에서 작성, 결제, 신고 등 서버 변경 기능은 사용하지 않습니다.
- 프로필과 콘텐츠 이미지는 촬영용 외부 이미지 URL을 사용하므로 인터넷 연결이 필요합니다.
- 앱 심사 또는 일반 TestFlight 배포에는 이 환경변수를 포함하지 않습니다.
