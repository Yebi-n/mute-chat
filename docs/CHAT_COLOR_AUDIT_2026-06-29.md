# 색연필·말풍선 점검 결과

점검일: 2026-06-29

## 현재 규칙

- 기본 말풍선은 `#F5F5F5`, 기본 텍스트는 `#1C1C1C`다.
- 유료 색연필, 말풍선, 커스텀 색상, 채팅 배경은 포인트 상품이다.
- 모든 채팅 색상 상품의 이용 기간은 구매 시점부터 7일이다.
- 구매한 색상은 계정의 모든 방에서 선택할 수 있다.
- 실제 선택값은 `room_member_chat_styles`에 방별로 저장되며 다른 멤버에게도 같은 색으로 보인다.
- 서버는 활성 entitlement가 없는 유료 색상 ID를 저장하지 못하게 막는다.
- 만료된 상품은 서버 조회 시 기본 말풍선·텍스트·배경으로 폴백한다.

## 이번 보완

- 앱이 열린 상태에서 상품이 만료되어도 가장 가까운 만료 시각에 entitlement와 방별 스타일을 다시 읽어 기본값으로 복구한다.
- 커스텀 말풍선, 텍스트, 배경 entitlement 유형을 각각 `bubble_color`, `text_color`, `background_color`로 정규화한다.
- 기존 커스텀 entitlement도 마이그레이션에서 정규화한다.
- 스토리 채팅 미리보기 본문은 작성자의 색연필 색을 사용한다.
- 스토리 채팅 미리보기 아이콘과 안내 문구는 현재 앱 테마 색을 사용한다. 화이트는 검정 계열, 다크는 흰색 계열을 사용한다.

## 확인된 방어 로직

- 포인트 부족 시 서버에서 구매를 거절한다.
- 같은 색상 상품을 다시 구매하면 새 구매 시점 기준 7일로 갱신한다.
- 커스텀 색상 슬롯은 종류별 최대 10개다.
- 만료된 커스텀 슬롯은 다시 구매할 수 있다.
- 색상 값은 `#RRGGBB` 형식만 허용한다.
- 방 멤버가 아닌 계정은 방별 스타일을 저장할 수 없다.

## 남은 QA

1. 두 계정에서 같은 방에 접속해 말풍선·텍스트 색상이 실시간으로 동일하게 보이는지 확인한다.
2. 구매 직후, 앱 재실행 후, 로그아웃 후 다른 계정 로그인 시 entitlement가 섞이지 않는지 확인한다.
3. 7일 만료 테스트는 서버 테스트 계정의 만료 시각을 짧게 설정해 앱이 열린 상태와 닫힌 상태를 각각 확인한다.
4. 밝은 말풍선과 밝은 텍스트처럼 대비가 낮은 조합은 추후 WCAG 대비 경고를 추가한다.
